# Installation

This project can be installed in developer mode on Chrome and Firefox.

## Install From GitHub Releases (Recommended)

1. Open the repository on GitHub.
2. Open the `Releases` page.
3. Open the latest release and download one of the zipped build files.
4. Extract the downloaded zip.

Then follow the browser-specific steps below.

## Load On Chrome (Developer Mode)

1. Open `chrome://extensions`.
2. Enable `Developer mode` (top-right).
3. Click `Load unpacked`.
4. Select the extracted folder or local folder.

## Load On Firefox (Temporary Add-on)

1. Open `about:debugging`.
2. Click `This Firefox`.
3. Click `Load Temporary Add-on...`.
4. Inside the extracted folder or local folder, select `manifest.json`.

Note: Firefox temporary add-ons are removed when Firefox is closed, so load it again after restart.
